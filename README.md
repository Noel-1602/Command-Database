# Terminal Commands Database for macOS/Linux

This repository contains a comprehensive, structured reference guide of essential terminal commands categorized by application. Each file contains descriptions, syntax, options, and practical command-line examples.

## Categories

* 📂 **[File System Navigation](file_system_navigation.md)**: Tools to explore directory paths, list folders, and search directories.
* 📝 **[File Manipulation](file_manipulation.md)**: Create, copy, rename, delete, read, modify permissions, archive, and process text.
* 🌐 **[Networking](networking.md)**: Port scans, DNS queries, SSH, secure file synchronization, curl, and connection diagnostics.
* ⚡ **[Process Controls](process_controls.md)**: Manage active jobs, background commands, signals, processes, and service logs.
* 📊 **[Monitoring](monitoring.md)**: Analyze system resources, disk usage, active open files, CPU, memory, and kernel buffers.
* 👤 **[Identity](identity.md)**: Audit current logins, groups, session histories, and user ID identifiers.
* 🔑 **[Privilege Escalation](privilege_escalation.md)**: Execute administrative actions, substitute user shells, and validate configs.
* 🐳 **[Docker](docker.md)**: Container lifecycle management, image construction, networks, storage volumes, and compose scripts.
* 🛠️ **[Others](others.md)**: Terminal customization, history searches, parameter parsing, cron jobs, and utility commands.
